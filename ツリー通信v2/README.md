# ツリー通信v2

「ツリー通信システム」の再構成用フォルダです。現行の通信作成画面を引き継ぎ、予約システムへの取込みと、ご家族が日々を振り返れる体験へ段階的に育てます。

**現在はローカル開発専用です。既存の児童・通信・予約データには接続していません。**

## 現行とV2の区別

| 項目 | 現行ツリー通信システム | このV2 |
|---|---|---|
| コード | `../branch/` | このフォルダ |
| サイト | `https://test-branch-46c5a.web.app/` | `http://127.0.0.1:5183/` |
| データ | 既存Firebase（複数アプリで共有） | ローカル `demo-tree-tsushin-v2` |
| アカウント | 現行の認証情報 | ローカル開発ログインのみ |
| 公開・予約連携 | 別システム | 未接続 |

起点は `TreeKids-School/branch` の `20b3bc63a91a7d87c3e0964ac6f9f3e1e473674b`、`branch/` 配下です。元のコードと配信環境を変更せず、`src/`、UIアセット、依存関係を引き継いでいます。認証情報の書出し、Firebase設定、旧Functions、配備スクリプト、修復用の単発スクリプトはコピーしていません。

## 起動

Node.js/npm、Java 21、Firebase CLIが必要です。Firebaseへのログインはローカルの画面操作には不要です。初回の依存関係とエミュレーターの取得にはインターネット接続を使います。

```powershell
cd C:\Users\koi06\treeproject\tree-branch\ツリー通信v2
npm ci --ignore-scripts
npm run emulators
```

別のターミナルで同じフォルダから起動します。

```powershell
npm run dev
```

`http://127.0.0.1:5183/` を開いて「ローカル開発環境を開く」を押します。エミュレーター管理画面は `http://127.0.0.1:4184/`。現行のID・パスワードは入力しません。

- 初期状態は空です。既存データの取込みや児童の自動投入は行いません。
- 検証データだけを扱ってください。認証はメモリ内保持なので再読込時に入り直します。
- エミュレーターのデータは終了時に `.runtime/emulator-data/` に保存し、次回起動で読み込みます。強制終了時は保存されない場合があります。このフォルダはGit対象外です。
- サーバーはループバックアドレスに限定しています。スマートフォンからの外部接続やクラウド配備はまだできません。

## 今回施した分離

- Firebaseの接続先をソース内で `demo-tree-tsushin-v2` とローカルAuth/Firestoreに固定。
- 実サイト上での起動を拒否。ブラウザの接続制限もローカルの指定ポートに限定。
- 起動時の古い変更履歴削除、外部ウィンドウからのログイン情報受信を除去。
- ブラウザの下書き・設定保存キーをV2専用に変更。
- 保存失敗時に別の保存先へ切り替えて成功扱いにする処理を停止。
- 残存AIフックを未接続として停止。外部送信・LINE送信・予約連携は実装前。
- `npm run deploy` は意図的に失敗。新しい配備先は未決定。親フォルダの配備設定は使わない。

ビルド：`npm run build`。分離確認：`npm run guard`。従来のUIと保存処理の大部分は引継ぎ段階であり、全業務の動作保証を意味しません。

# ツリー通信v2 作業ルール

## 2026-10-05 利用者の追加指示: 日々のあしあとへの公開

- 保存したツリー通信を確認・選択し、保護者の「日々のあしあと」に明示公開する機能を追加する。公開後の変更は再公開するまで保護者へ反映せず、公開取り消しにも対応する。
- 入力完了、手動送信確認、LINE受付は保護者画面への公開承認ではない。未公開本文や内部メモを保護者のデータ領域へ自動保存しない。
- 対象児童に紐付いた保護者だけが閲覧できるよう予約V2サーバーと連携する。旧通信や実レコードを検証目的で公開しない。

## 2026-10-05 利用者の追加指示: 送信管理・公式LINE一斉送信

- 一覧の手動送信完了チェックと色分け、内容確認済みの通信を連携保護者へ公式LINEから一斉送信する機能を実装する。従来の「保護者公開は未接続」は、この明示的な送信機能について更新する。
- 入力完了・手動送信確認は送信許可とみなさない。保存本文の確認、サーバーで確定した宛先と本文のプレビュー、明示的な一斉送信を経由する。
- 宛先は予約V2の有効な保護者リンクとサーバーで本人確認済みのLINE情報を使用する。送信API・秘密情報は予約V2サーバーで扱い、iframeへ渡さない。
- 送信結果はLINE APIの受付として表示し、配達や既読を断定しない。実装確認のための実際の保護者宛送信は行わない。

## 2026-10-05 利用者の追加指示: V2共有保存とデータコピー

- 既存通信DBの業務データを予約V2の `tree-schedule-v2` 内の通信専用領域へコピーし、稼働可能にすることが明示的に許可された。以下の旧「未移行・未共有」制限は、この作業について更新する。
- 元の通信DBは読取り専用。既存データの変更・削除、旧サーバー権限の変更は行わない。認証ユーザー・パスワード・トークンはコピーしない。
- 児童は既存の対応関係または一意に一致する氏名（生年月日等の矛盾なし）で予約V2のIDへ対応付ける。曖昧な同名は統合せず記録する。事業所は予約V2を正とする。
- スタッフの業務名簿とログイン権限は区別する。名簿照合から認証アカウントや権限を自動作成しない。
- 公開用iframeは予約V2側の認証付き通信を使う。トークンやパスワードをiframeへ渡さず、共有保存の失敗を端末保存の成功として扱わない。
- コピーの検証・再実行時の上書き防止・移行結果を残す。個人データのスナップショットはgit管理外の `.runtime/` に限り、ソースやHosting配信物へ含めない。
- デプロイ先・コマンドは予約V2のガード付き `deploy:dev:*` のみとする。

## 2026-10-04 予約V2内での起動についての追加指示

- 所有者の指示により、予約V2のスタッフメニュー内で起動確認版を公開する。
- `npm run build:portal` はFirebaseを使わないブラウザー内保存版を生成する。予約V2の `public/tree-communication-v2/` に組み込み、予約V2側のガード付き配備コマンドだけで公開する。
- 現行のデータ移行、V1の権限変更、新サーバーへの共有保存はまだ行わない。上記以外の既存の制限は維持する。
- 予約V2のスタッフ認証を入口に使う。認証トークンやパスワードはiframeに渡さない。仮保存はUID別に分離し、未移行・未共有と表示する。

- 所有者は2026-10-04、このフォルダで「ツリー通信システム」の再構成を開始するよう指定した。
- 編集対象はこのフォルダ内。親の `branch/`、リポジトリ直下の旧アプリ・Functions・Firebase設定は参照専用。
- 元コードは `TreeKids-School/branch` のコミット `20b3bc63a91a7d87c3e0964ac6f9f3e1e473674b`、`branch/` 配下。
- 既存の児童・通信・日報・職員・認証データを変更、移動、削除しない。移行はこの段階では行わない。
- 接続先は `demo-tree-tsushin-v2` のローカルAuth/Firestoreエミュレーターだけ。既存Firebase接続設定、トークン、ユーザー書出しデータを持ち込まない。
- `npm run dev` / `build` / `emulators` の分離ガードを維持する。`npm run deploy` は意図的に失敗する。親階層の配備スクリプトを使わない。
- V2の公開先は未決定。旧Hostingサイト、予約V2、共有Firebaseへの配備・ルール変更・Functions公開はこの作業に含まれない。
- 機能を削って完成扱いにしない。機能台帳と未接続項目を `docs/` に残す。
- 予約連携は原文を残す取込候補→児童・事業所の対応確認→下書き→明示的な公開に分ける。通信完了や手動送信チェックを公開許可とみなさない。
- 元データへの逆方向書込・削除同期はしない。写真・バディ文は未実装と表示する。
- `public/logo.png` はワークスペース指定の正式ロゴ。比率・画像全体を維持する。
- コミットはこのフォルダの変更だけをステージし、featureブランチへプッシュする。

## 2026-10-05 利用者指定：常時編集許可とLINE送信の簡略化

- このフォルダは常時編集可能。ルートAGENTS.mdの現行アプリ一覧にも追加済み。
- LINE送信を児童選択→まとめて本文確認→宛先・本文の最終確認と明示送信に整理する。児童ごとの確認チェックと最後の重複チェックをなくし、明示的な確認ボタンで既存のサーバー確認記録を保存する。宛先検証・変更検知・二重送信防止を維持する。

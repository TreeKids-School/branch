# 予約V2の中で使うツリー通信v2 — 画像モック改訂版

2026-10-04作成。スマホ8枚・PC4枚、計12枚をすべて組込みの `image_gen` で生成したUI・UX提案です。CLI/APIスクリプトによる画像生成は使用していません。

前回の独立アプリに見える案を改訂し、予約V2の現行外枠と「ツリー通信v2」の入口を引き継ぎました。スマホを先に検討し、療育中の片手入力、キーボード表示、中断と再開、保存失敗の救済を含めています。集中入力中も、予約V2内であることと戻り先を残す提案です。

[ギャラリーを開く](index.html)。画像クリックで拡大、左右キーで前後移動、Escまたは「閉じる」で一覧に戻ります。各画像の直接リンクからも閲覧できます。

## 現行機能と提案の境界

- 現在の通信V2は、利用者ごとのブラウザー内仮保存です。端末をまたぐ共有、旧データ移行、新サーバー接続は行っていません。
- 予約V2から通信V2へ児童・日付・事業所を自動で引き継ぐ処理はありません。画像の児童名・本文・件数は表示例です。
- **予約V2自身には** `CommunicationEditor` の下書き保存・公開・公開更新・非公開と、`ParentCommunicationPage` の「日々のあしあと」が実装されています。**通信V2からこの経路へは未接続**です。
- コピー成功、入力完了、手動送信確認、保護者公開は別の状態です。AIバディや写真の接続も実装済みとは扱いません。
- 既存機能を維持するための画面配置を示す提案であり、実アプリのUI変更は行っていません。**資料のみの更新のため、アプリのビルド・デプロイは不要です。**

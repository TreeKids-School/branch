今日の気づきが、家族の記憶になる。

12画面・すべて画像生成による検討用モックアップ

毎日の仕事を進めやすくしながら、残した言葉をあとから読み返せる場所へ。既存の機能を引き継ぐ画面と、バディや保護者向けの将来案を、一つの流れで整理しました。

今日の準備 → 記録する → 通信を整える → 届ける → 振り返る

アプリ本体・既存データ・配信環境は変更していません。
画面の人物・本文・写真・件数はすべて作例です。現在の通信V2はブラウザー内仮保存版で、共有・移行・AI・写真・保護者公開は未接続です。

仕事の途中を失わない

自動保存、下書き、完了解除、同時編集の保護、変更履歴を引き継ぐ。新しい画面でも、既存データの項目を落とさない。

届けたことを取り違えない

具体的な一場面を大切にする

成長を点数にせず、その日の言葉と様子を読み返せる形にする。バディの言葉は原文を根拠に、スタッフが確かめる。

画像はレイアウト・雰囲気・導線を検討するためのものです。細かな文字・数値・日付・アイコン・選択状態は最終仕様ではありません。各画面は異なる作業時点の作例であり、実データの連続した操作履歴ではありません。実装では正式ロゴPNGをそのまま使用し、モック内のロゴや文字を切り出して流用しません。
